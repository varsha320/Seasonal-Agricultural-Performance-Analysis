# Seasonal Agricultural Performance Analysis

## 1. Project Overview

This project analyzes agricultural performance across different crops and seasons using environmental, soil, agricultural input, yield, water-efficiency, and economic variables.

The analysis uses exploratory data analysis and statistical techniques to identify patterns and relationships in agricultural performance.

## 2. Problem Statement

Agricultural performance is influenced by several factors such as rainfall, temperature, soil conditions, irrigation, agricultural inputs, crop type, and season.

This project aims to analyze the available agricultural dataset to understand variations in yield, profitability, water efficiency, and disease/pest risk across different crops and seasons.

## 3. Objectives

- Analyze the structure and characteristics of the agricultural dataset.
- Identify and handle missing values and duplicate records.
- Validate important relationships among agricultural variables.
- Compare crop and seasonal performance.
- Analyze relationships between environmental and agricultural variables.
- Study factors associated with yield and profit.
- Statistically evaluate differences in yield and profit across seasons.
- Provide data-driven agricultural insights and recommendations.

## 4. Dataset

The dataset contains 4,000 agricultural farm records and 28 variables.

The variables include:

- Farm information
- State and district
- Crop and season
- Farm area
- Rainfall
- Temperature
- Humidity
- Sunlight
- Soil characteristics
- Agricultural inputs
- Yield and production
- Market price
- Cost, revenue, and profit
- Water usage and efficiency
- Disease and pest risk

## 6. Key Findings

The analysis identifies differences in agricultural performance across crops and seasons.

Sugarcane shows substantially higher average yield and profitability than the other crops in the dataset.

Kharif has the highest observed average yield, profit, and water efficiency among the three seasons.

Statistical analysis indicates that seasonal differences in yield are not statistically significant, whereas seasonal differences in profit are statistically significant.
